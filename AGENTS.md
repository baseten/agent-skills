# AGENTS.md

The instructions for changing this repository are in **`CLAUDE.md`**. Read it before
editing any `skills/*/SKILL.md` or `NOTES.md`, and before resolving a review round.

This file is a pointer and not a copy. A second copy of those instructions here would be a
summary maintained separately from the rules it summarises — the failure mode `CLAUDE.md` is
largely about — so it points instead of restating, and it deliberately does not paraphrase
or qualify anything in it.

Applies to every agent reading this repository, whichever filename its convention looks
for: `CLAUDE.md` is the single source.
