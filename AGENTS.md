# AGENTS.md

The instructions for changing this repository are in **`CLAUDE.md`**. Read it before
editing any `skills/*/SKILL.md` or `NOTES.md`, and before resolving a review round.

This file is a pointer and not a copy, deliberately. `CLAUDE.md` requires that a rule
stated twice be collapsed to one statement plus a pointer, because restatement is how two
copies of a rule come to disagree — see *The consequence sweep*. A second copy of those
instructions here would be the first thing to violate them.

Applies to every agent reading this repository, whichever filename its convention looks
for: `CLAUDE.md` is the single source.
